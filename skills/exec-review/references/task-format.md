# 任务文本格式

给 `run-task.mjs` 一段任务说明即可。

## 推荐：Markdown 文件（`--task-file`）

```markdown
# 简短标题

id: 可选标签

## 正文

要做什么。验收说明、约束、相关链接。

## 要求

可选的更细要求。没有就省略本节。
```

- 第一个 `#` 标题 → 标题（也可用 `--title`）
- 靠前的 `id:` 行 → 可选标签（写入摘要，便于你对照）
- 优先用 `## 正文` / `## 要求`（也识别 `Body` / `Spec`）
- 若都没有分节：标题之后的全文当作正文

## 其他输入

- 标准输入：同样结构的 Markdown（加 `--stdin`）
- 参数：`--title`、`--body`、`--requirements`、`--id`
